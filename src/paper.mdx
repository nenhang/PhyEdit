## Abstract

Achieving physically accurate object manipulation in image editing is essential for its potential applications in interactive world models. However, existing visual generative models often fail at precise spatial manipulation, resulting in incorrect scaling and positioning of objects. This limitation primarily stems from the lack of explicit mechanisms to incorporate 3D geometry and perspective projection. To achieve accurate manipulation, we develop <SmallCaps>PhyEdit</SmallCaps>, an image editing framework that leverages explicit geometric simulation as contextual 3D-aware visual guidance. By combining this plug-and-play 3D prior with joint 2D–3D supervision, our method effectively improves physical accuracy and manipulation consistency. To support this method and evaluate performance, we present a real-world dataset, <SmallCaps>RealManip-10K</SmallCaps>, for 3D-aware object manipulation featuring paired images and depth annotations. We also propose <SmallCaps>ManipEval</SmallCaps>, a benchmark with multi-dimensional metrics to evaluate 3D spatial control and geometric consistency. Extensive experiments show that our approach outperforms existing methods, including strong closed-source models, in both 3D geometric accuracy and manipulation consistency.

</HighlightedSection>

## Method

<SmallCaps>PhyEdit</SmallCaps> combines a DiT editing backbone with a 3D foundation model. The framework consists of three components: (1) a **3D transformation module** that generates a depth-aware preview, (2) the **DiT denoising backbone**, and (3) a **joint training loss** in both 2D latent and 3D depth spaces.

### 3D Transformation Module

Given a source image $I_\text{src}$, object mask $M_o$, and transition vector $\Delta\mathbf{p}_o$, we first predict depth $D$ and camera pose $(R, t)$, then edit the object directly in 3D space:

$$
\mathbf{P}_{o}=\operatorname{Unproj}(I_{\text{src}}, M_{o},D,R,t)
$$
$$
\mathbf{P}_{o}'=\mathbf{P}_{o}+\Delta\mathbf{p}_o
$$
$$
I_{\text{prev}}=\operatorname{Proj}(\mathbf{P}'_o,R,t)
$$

The preview image $I_\text{prev}$ serves as an additional condition for the DiT backbone, providing explicit geometric guidance and naturally supporting multi-object manipulation.

### Joint Supervision

Latent-space denoising loss alone is insufficient for 3D manipulation, as it emphasizes appearance reconstruction over geometric correctness. We add a depth-space supervision term using the scale-invariant logarithmic (SILog) loss:

$$
\mathcal{L} = \mathcal{L}_{\text{flow}} + \lambda_d \mathcal{L}_{\text{depth}}
$$

where $\lambda_d = 0.1$ balances latent and depth supervision. Compared to methods requiring heavy architecture changes to inject 3D priors, our approach only adds lightweight conditioning and training design, making it easy to plug into different DiT-based editors.

## RealManip-10K Dataset

Existing datasets place little emphasis on 3D-aware spatial changes and real-world physical laws. We build <SmallCaps>RealManip-10K</SmallCaps>, a real-world dataset of paired images $(I_\text{src}, I_\text{tgt})$ where objects are manipulated in 3D space—especially along the depth axis. Each pair provides depth maps, object masks, and representative 3D object coordinates.

Key features of the dataset:
- Each pair contains an object with significant depth change
- Includes samples with partial occlusion, emphasizing near-far relationships
- Contains pairs with multiple simultaneously manipulated objects

  <Figure>
    <Picture slot="figure" src={datasetPipeline} alt="The four-stage pipeline used to construct RealManip-10K" />

The pipeline collects videos from high-resolution sources (OpenVid-1M, VIDGEN-1M, PE-Video-Dataset) and object-tracking datasets (LaSOT, GoT-10K, TrackingNet). A novel **camera token clustering** approach using DBSCAN ensures near-static camera conditions for reliable manipulation supervision.

## ManipEval Benchmark

We design <SmallCaps>ManipEval</SmallCaps> with 200 image pairs (~320 individual objects) covering diverse scenes, object categories, and scales. Metrics span five dimensions:

| Dimension | Metric | Description |
| :--- | :---: | :--- |
| 2D Spatial Accuracy | DIoU ↑ / Mask IoU ↑ | Box and mask overlap with ground truth |
| Depth Accuracy | AbsRel ↓ / δ₁.₂₅ ↑ | Per-pixel depth error on object region |
| 3D Manipulation Accuracy | Chamfer ↓ / Centroid ↓ | Point cloud distance to ground truth |
| Image Quality | RA-DINO ↑ / DeQA ↑ | Relocation-aware DINO similarity and perceptual quality |
| Physical Plausibility | Phys-VLM ↑ | VLM-based assessment of physical realism |

### Continuous Object Manipulation

Beyond single-step editing, <SmallCaps>PhyEdit</SmallCaps> maintains geometric consistency under continuous state transitions. Given an initial state and spatial trajectory, our model sequentially renders physically accurate keyframes that can be processed by video interpolation models to synthesize continuous manipulation videos.

### Ablation Studies

**Depth Supervision.** We compare three depth supervision strategies. Pixel-level supervision—decoding the denoised latent and supervising its depth map—consistently outperforms latent-space variants.
